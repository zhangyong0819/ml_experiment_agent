# ImportError evidence

ImportError and ModuleNotFoundError

Read the exact module name and traceback. The environment may be missing a dependency or may use an incompatible module layout; the exception alone does not establish which installation command would fix it. Use the registered project's interpreter and dependency metadata as context. Phase 3A cannot install packages, invoke shell commands or change the environment. Record observed import evidence without inventing a package version.
